# HUMIS Website
## *Further HTML and CSS*
### Elliot Murray

The aim of this project was to recreate a handful of webpages based on a mock-up PDF, learning and practicing HTML and CSS skills in the process. This is a theoretical website for the University of Utah College of Humanities.

I learned: to work with HTML and CSS files in the WebStorm IDE; the difference between inline and block level elements; divs, spans, sections, and asides; using classes to distinguish otherwise identical tags serving different purposed, h1 through h6, p, a, img, svg, body, main, header, footer, nav, strong, br, and i tags; writing root level styles and vars; linking multiple style sheets in one html page, and linking style sheets within style sheets; flexbox properties, borders, radii, corners, and more.

If I had to work on a similar project in the future, I think I would start with just trying to work out as much of the CSS as possible across all of the pages before starting to build them out, in order to keep a more concise and organized style sheet. With this project, I often found myself creating classes that would only be used once or twice and appending them to the style sheet, so there's probably some unnecessarily repeated code - though, at the same time, the PDF I was working from had some instances where even elements that seem like they should have been handled the same way were implemented differently between pages.
